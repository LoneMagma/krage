# kRAGE v0.9

Rook, Vera and Blake now use original block-built bodies (372, 396 and 408 triangles respectively), with green, blue and plum outfits. Cap, hair, scarf, hood and gear distinguish the silhouettes. The previous dense faceted bodies are no longer loaded. Joint topology, team markers, hitboxes, cosmetics selection and ragdoll compatibility remain shared. Idle legs are straight; running keeps planted feet with speed-dependent compression. Lobby hands use weapon grip targets.

Ground response is faster, jump buffering is 150ms and mid-air WASD actively redirects horizontal velocity. Slide-jumps retain momentum; air steering cannot manufacture extra speed. Prediction and the authoritative server execute the same movement code. Bots check space before strafing and briefly search an opponent's last actually seen position after losing sight, without tracking unseen movement.

Weapons use crisp box components and lower-segment barrels. KILO has a clearer wood-stock/gas-tube silhouette and curved magazine; ECHO keeps a compact angular profile; MICA has paired barrels and a low bead sight with matching ADS height. Existing finishes remain supported. EDGE has a correctly aligned gripping hand, angled ready pose and restrained alternating slash arcs, retaining separate timed slash/stab mechanics.

Lobby navigation is centered with distinct active tabs, framed map choices and previous/next map arrows. Both Cells are open to sky again, with shorter perimeter walls and restored outdoor lighting. Snow gains two collidable utility props, generator vents/indicators, contrasting upper wall panels and softer snow texture variation. No progression/account overhaul or deployment was performed.

Deploy frontend and rooms together using protocol 14; older clients must reload. Version remains pre-v1: validate actual player comfort, low-end device performance and deployed networking with friends.

Verification: 125 passing tests (58 simulation, 38 presentation, 29 server), TypeScript, lint and production build. Production browser checks passed at 1280×800 and 900×650 without page overflow or JavaScript exceptions; map arrows cycle all four arenas. Frontend HTTP and room protocol-14 health checks passed. Human online play and hardware performance are not measured by these checks.
